# Mitwirken

## Was willkommen ist

- **Fehlermeldungen** — reproduzierbare Bugs mit kurzer Beschreibung (was getan, was erwartet, was passiert)
- **Verbesserungsvorschläge** — konkrete Ideen, gerne mit Begründung

Beides am besten als Issue auf [Codeberg](https://codeberg.org/Stheel/stroemling).

## Was nicht angenommen wird

**Code-Beiträge (Pull Requests) werden nicht angenommen.**

Das Projekt wird alleine mit KI-Unterstützung entwickelt. Das ist bewusst so — kein Misstrauen, sondern eine Entscheidung über den Entwicklungsweg.

Wer das Projekt in eine andere Richtung weiterentwickeln möchte, kann es forken. Die GPL-3.0-Lizenz erlaubt das ausdrücklich.
